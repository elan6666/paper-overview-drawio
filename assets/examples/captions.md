# Demonstration captions

1. Conditional prediction through latent addition. A control-expression encoder produces a cell representation. A perturbation identifier selects an embedding from a graph encoder; its sum with the cell representation is decoded into predicted expression.

2. Main prediction path and conditioning detail. The left panel shows control encoding, addition and decoding. The right panel shows how the perturbation embedding is computed and selected before entering the left prediction path. Dashed arrows denote conditioning.

3. Staged information processing. The same conditional predictor is organized as inputs, representations and response. Solid arrows indicate data flow and dashed arrows indicate conditioning.

These diagrams define an illustrative computation only and contain no experimental results.
