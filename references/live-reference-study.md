# Learn the visual language for this paper now

Use the target manuscript to form search terms: application/problem, central model idea, data modality and intended venue community. Search official publisher/proceedings sources for related work and accessible PDFs. Suitable references can include a close task match, a useful mechanism diagram and a strong overview in the adjacent field. Avoid assuming a preprint has been accepted; verify venue identity where it matters.

Open the actual figures, not just abstracts. Captions reveal whether a thumbnail is a schematic, a real dataset summary or an empirical result. Inspect the complete figure and useful details. For local PDFs, render the relevant pages and verify that crops retain the entire figure. A downloaded PDF or extracted caption alone is not visual study.

Make concise task-local notes: title/venue, source link, figure/page, what the panel layout explains, what can transfer to this paper, and what scientific content cannot. The notes are a working brief rather than a reusable style taxonomy. Existing PDFs may save retrieval time but should be re-selected for the new manuscript; do not mechanically reuse a fixed corpus.

During design, revisit reference figures at comparable display size. Notice the balance of main story and detail, meaningful object glyphs, color roles, label density and whitespace. Learn the visual grammar and create original artwork. Preserve uncertainty about whether an overview thumbnail has real data behind it; never infer a chart's software from appearance.

When review identifies a gap, return to the relevant reference detail, adjust the new composition and inspect again. Do not extend the literature search indefinitely once the design question has been answered.
